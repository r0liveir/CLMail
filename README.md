# CLMail - An email parser tool example

Part of **Introduction to Applied AI Engineering - USPCodeLab**

## Setup

Before running, make sure you have a Groq key exported:

```bash 
$ export GROQ_API_KEY=<your-key-here>
```

Activate a `venv`, install the packages with `uv` or `pip`, and run an initial example:

```bash
$ uv run clmail src/texts/email1.txt
```

Now, you can experiment with e-mails, add more services, and keep expanding this application into a full tool \o/

This repository also has a `starter` skeleton where you can fill in the blanks. Read more on `starter/`
